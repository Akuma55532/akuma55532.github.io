原因是网络时钟同步引起的，比如说，你在一个没有wifi的场景下启动了无人机，然后又将无人机移动到有wifi的场景，那么机载电脑会自动进行网络时钟同步，从1s的时间戳瞬间跳变到自1970年开始计时到至今为止的时间戳，导致imu和激光雷达的时钟同步直接崩溃。

解决方案：`sudo timedatectl set-ntp off`关闭网络时钟同步就好了，但是这就导致没办法正常访问公网了，需要的时候再`sudo timedatectl set-ntp on`即可。

Linux 刷完系统之后没有网络图标，网卡是Intel的，结果半天找不到对应的linux驱动程序？

我在给Jetson刷完Jetpack6.2的固件之后，发现我的WIFI图标没了，网卡型号是AC 8265，以为是没有驱动，半天也没找到对应驱动程序。

解决方案：用USB连接手机与对应设备，打开USB网络共享，接下来在对应设备终端输入下面指令

~~~
sudo apt update && sudo apt install iwlwifi -y
sudo modprobe iwlwifi
~~~

ros-humble-pcl-ros包找到不到？

输入`sudo apt-get insatll ros-humble-pcl-ros`之后，结果显示没有找到这个包该怎么办？

解决方案：原因是当前 APT 没有启用 ROS 2 软件源

1. 安装软件源配置包

逐段执行；有报错就先停下：

~~~bash
sudo apt install curl ca-certificates

ROS_APT_SOURCE_VERSION=$(curl -fsSL \
  https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["tag_name"])')

echo "$ROS_APT_SOURCE_VERSION"
~~~

上面应输出版本号，然后执行：

~~~
curl -fL -o /tmp/ros2-apt-source.deb \
"https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.jammy_all.deb"

sudo dpkg -i /tmp/ros2-apt-source.deb
sudo apt update
~~~

2. 安装缺少的依赖

~~~
sudo apt install ros-humble-pcl-ros
~~~
