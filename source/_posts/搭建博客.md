无论在哪个行业，将所学的知识记录下来都是一个很好的习惯，人会遗忘，数据不会。

## 环境搭建

### Nodejs安装（Optional）

我们需要在本地安装nodejs和npm是为了在本地测试

``` bash
Nodejs环境下载官网: https://nodejs.org/zh-cn/download
Nodejs版本选择: v22.23.1-LTS
```

windows用户可以直接下载msi文件双击安装
linux用户使用命令行安装比较方便

### Git安装

我们需要安装git

``` bash
官方网址: https://git-scm.com/
```

windows用户下载exe安装包
linux用户直接执行下面命令即可

``` bash
sudo apt update && sudo apt install git
```

## 本地安装hexo

``` bash
hexo官方文档: https://hexo.io/zh-cn/docs/
```

找到一个为博客准备的空白文件夹，执行下面命令

``` bash
npm install -g hexo-cli
```

初始化

``` bash
hexo init .
npm install
```

更改一些自定义项（这里列举了一些我的更改项）

先安装我当前在用的主题 `Fluid`

``` bash
npm install --save hexo-theme-fluid
```

然后修改根目录下的 `_config.yml`

``` yaml
# Site
title: Akuma55532's Blog
subtitle: ''
description: ''
keywords:
author: Akuma55532
language: zh-CN
timezone: Asia/Shanghai

# URL
url: https://akuma55532.github.io

# Theme
theme: fluid
```

接着把 `node_modules/hexo-theme-fluid/_config.yml` 复制到博客根目录，重命名为 `_config.fluid.yml`

``` bash
cp node_modules/hexo-theme-fluid/_config.yml _config.fluid.yml
```

然后修改 `_config.fluid.yml` 里一些常用的自定义项，例如：

``` yaml
navbar:
  blog_title: "Akuma55532"
  menu:
    - { key: "home", link: "/", icon: "iconfont icon-home-fill", name: "首页" }
    - { key: "archive", link: "/archives/", icon: "iconfont icon-archive-fill", name: "归档" }
    - { key: "about", link: "/about/", icon: "iconfont icon-user-fill", name: "关于" }

index:
  banner_img: /img/home-banner.jpg
  banner_img_height: 85
  banner_mask_alpha: 0.35
  slogan:
    enable: true
    text: "记录技术、想法和日常。"

about:
  enable: true
  avatar: /img/avatar.png
  name: "Akuma55532"
  intro: "一名持续学习中的开发者。"
  icons:
    - { class: "iconfont icon-github-fill", link: "https://github.com/Akuma55532", tip: "GitHub" }
    - { class: "iconfont icon-mail-fill", link: "mailto:you@example.com", tip: "Email" }

color:
  navbar_bg_color: "#0f172a"
  navbar_text_color: "#f8fafc"
  subtitle_color: "#e2e8f0"
  text_color: "#334155"
  board_color: "#ffffff"
  post_link_color: "#2563eb"

footer:
  content: '
    <span>© 2026 Akuma55532</span>
  '
```

如果你还想创建关于页，可以执行：

``` bash
hexo new page about
```

然后编辑 `source/about/index.md`

``` yaml
---
title: About
layout: about
---

这里写你的个人介绍
```

图片资源我建议统一放在 `source/img/` 目录，比如：

``` bash
source/img/avatar.png
source/img/home-banner.jpg
```

这样在配置文件里就可以直接写：

``` yaml
/img/avatar.png
/img/home-banner.jpg
```

编译

``` bash
hexo build
```

测试

``` bash
hexo server
```

这时候你可以在`localhost:4000`访问你的博客了
